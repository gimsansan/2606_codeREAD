**다른 노트북에서 쓰는 방법** (배포 URL 기준)

## 1. 앱만 쓰기 (가장 간단)

1. 다른 노트북 브라우저에서 **`https://2606-code-read.vercel.app`** 접속  
2. (원하면) **앱 설치** → 작업 표시줄에 SnippetNote  
3. 그대로 사용  

→ **npm, Vercel, Git 필요 없음.**

---

## 2. 지금 노트북 데이터까지 옮기기

데이터는 **기기마다 따로** 저장됩니다. 옮기려면 백업:

**지금 노트북**
1. SnippetNote → **내보내기**  
2. `snippetnote-2026-xx-xx.json` 저장 (USB, 클라우드, 카톡 등)

**다른 노트북**
1. `2606-code-read.vercel.app` 접속  
2. **가져오기** → JSON 선택 → 확인  

→ 카테고리·페이지 **전부 복구**.

---

## 3. 개발/수정까지 다른 노트북에서

```bash
git clone https://github.com/gimsansan/2606_codeREAD.git
cd 2606_codeREAD/codeRead
npm install
npm run dev
```

→ 코드 수정용. **일반 사용만**이면 1번이면 됩니다.

---

## 정리

| 목적 | 방법 |
|------|------|
| 다른 PC에서 **앱만** | Vercel URL + (선택) PWA 설치 |
| **데이터까지** | 내보내기 → 파일 옮김 → 가져오기 |
| **코드 수정** | Git clone + npm |

**자동 동기화는 없음** — 기기 바꿀 때마다 **내보내기/가져오기** 또는 수동 입력 필요.
