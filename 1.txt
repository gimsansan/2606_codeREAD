## 높음 — 바로 손보면 좋은 것

### 1. 숨겨진 조작 (발견성)
- 카테고리 **더블클릭** 이름 수정, comment-panel **더블클릭** 수정 → `title` 툴팁만 있고 UI 힌트 없음
- **"페이지가 없습니다."** 클릭 가능 → hover 전에는 클릭 가능한지 모름

**제안:** 연필 아이콘, `클릭하여 추가` 문구, 빈 상태에 `+` 버튼

### 2. 편집 UX 불일치
- **comment-panel**만 보기 모드에서 인라인 수정
- **code-panel**은 **편집 모드** 진입해야 수정
- **닫기** = 편집 종료지만, 저장/취소 구분 없음 (실시간 localStorage 저장)

**제안:** code-panel도 더블클릭 수정, 또는 “인라인 수정은 설명만” 안내 문구

### 3. 페이지 삭제 규칙 혼란
- **빈 페이지** → 보기 모드에서도 삭제 버튼
- **내용 있는 페이지** → 편집 모드에서만 삭제

**제안:** 보기 모드에서도 삭제 가능 + confirm 유지, 또는 규칙 통일

### 4. 검색 2개 — 역할 혼동
| 위치 | 역할 |
|------|------|
| 좌 `전체 검색...` | 카테고리 넘나들기 |
| 우 `이 카테고리에서 검색...` | 현재 카테고리만 |

**제안:** 라벨/아이콘으로 구분 강화, 또는 한쪽에 `전체 / 이 카테고리` 탭

### 5. 페이지네이션 — 페이지 많을 때
- 지금은 `1 2 3 4 …` **숫자만** 표시
- 10개 넘으면 버튼 줄바꿈·가독성 저하
- 검색 안 할 때는 **title이 안 보임** (검색 시에만 `SearchResultList`)

**제안:** title 목록 항상 표시, 또는 `현재/전체` + 이전/다음만

## 중간 — 쓰다 보면 불편한 것

### 6. 카테고리 삭제 × — 오클릭 위험
- 항목마다 **×** 항상 노출, confirm만 있음
- hover 시에만 보이게, 또는 삭제 전 **길게 누르기** 등

### 7. 헤더 버튼 과밀
`편집 · +페이지 · 페이지 삭제 · 초기화` — 모바일에서 wrap

**제안:** `⋯` 메뉴로 `초기화`·`페이지 삭제` 묶기

### 8. 모바일 사이드바 `max-height: 200px`
카테고리 많으면 **200px 안에서만** 스크롤 → 답답함

**제안:** `40vh` 등 비율 높이, 또는 접기/펼치기

### 9. `language` 선택 — Viewer 반영 없음
`PageEditor`에 언어 select 있으나 **Viewer에 하이라이트/표시 없음** → 사용자 기대와 어긋남

### 10. comment-panel blur 저장
바깥 클릭 시 **즉시 저장**, Esc만 취소 → 실수 저장 가능

**제안:** 저장/취소 버튼 또는 blur 시 confirm
