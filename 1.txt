**SnippetNote(codeRead)** UX/UI 검토입니다. 코드 기준으로 **수정이 필요해 보이는 것**만 정리했습니다.

## 높음 — 바로 손보면 좋은 것

### 1. 숨겨진 조작 (발견성)
- 카테고리 **더블클릭** 이름 수정, comment-panel **더블클릭** 수정 → `title` 툴팁만 있고 UI 힌트 없음
- **"페이지가 없습니다."** 클릭 가능 → hover 전에는 클릭 가능한지 모름

**제안:** 연필 아이콘, `클릭하여 추가` 문구, 빈 상태에 `+` 버튼

### 2. 편집 UX 불일치
- **comment-panel**만 보기 모드에서 인라인 수정
- **code-panel**은 **편집 모드** 진입해야 수정
- **닫기** = 편집 종료지만, 저장/취소 구분 없음 (실시간 localStorage 저장)

**제안:** code-panel도 더블클릭 수정, 또는 “인라인 수정은 설명만” 안내 문구

### 3. 페이지 삭제 규칙 혼란
- **빈 페이지** → 보기 모드에서도 삭제 버튼
- **내용 있는 페이지** → 편집 모드에서만 삭제

**제안:** 보기 모드에서도 삭제 가능 + confirm 유지, 또는 규칙 통일

### 4. 검색 2개 — 역할 혼동
| 위치 | 역할 |
|------|------|
| 좌 `전체 검색...` | 카테고리 넘나들기 |
| 우 `이 카테고리에서 검색...` | 현재 카테고리만 |

**제안:** 라벨/아이콘으로 구분 강화, 또는 한쪽에 `전체 / 이 카테고리` 탭

### 5. 페이지네이션 — 페이지 많을 때
- 지금은 `1 2 3 4 …` **숫자만** 표시
- 10개 넘으면 버튼 줄바꿈·가독성 저하
- 검색 안 할 때는 **title이 안 보임** (검색 시에만 `SearchResultList`)

**제안:** title 목록 항상 표시, 또는 `현재/전체` + 이전/다음만

---

## 중간 — 쓰다 보면 불편한 것

### 6. 카테고리 삭제 × — 오클릭 위험
- 항목마다 **×** 항상 노출, confirm만 있음
- hover 시에만 보이게, 또는 삭제 전 **길게 누르기** 등

### 7. 헤더 버튼 과밀
`편집 · +페이지 · 페이지 삭제 · 초기화` — 모바일에서 wrap

**제안:** `⋯` 메뉴로 `초기화`·`페이지 삭제` 묶기

### 8. 모바일 사이드바 `max-height: 200px`
카테고리 많으면 **200px 안에서만** 스크롤 → 답답함

**제안:** `40vh` 등 비율 높이, 또는 접기/펼치기

### 9. `language` 선택 — Viewer 반영 없음
`PageEditor`에 언어 select 있으나 **Viewer에 하이라이트/표시 없음** → 사용자 기대와 어긋남

### 10. comment-panel blur 저장
바깥 클릭 시 **즉시 저장**, Esc만 취소 → 실수 저장 가능

**제안:** 저장/취소 버튼 또는 blur 시 confirm

## 바탕화면 앱(PWA) — 직접 하기 순서

### 0. 준비
- `dev`(5173) **끄기** — PWA 테스트는 **4173 또는 배포 URL 하나**만
- 작업 폴더: `d:\2605_month\2606_codeRead\codeRead`

---

### 1. PWA 패키지 설치
```bash
cd d:\2605_month\2606_codeRead\codeRead
npm install -D vite-plugin-pwa
```

---

### 2. `vite.config.js` 수정
`vite-plugin-pwa` 추가 + manifest 설정.

필수 항목:
- `name`, `short_name` (예: SnippetNote)
- `display: 'standalone'` ← 앱 창처럼 열림
- `icons` — **192×192**, **512×512** PNG (아래 3번)

공식 예시: [vite-plugin-pwa](https://vite-pwa-org.netlify.app/guide/)

---

### 3. 아이콘 추가
`public/` 폴더에 PNG 넣기 (예):
- `public/pwa-192.png`
- `public/pwa-512.png`

`icons.svg`를 PNG로 변환해도 됩니다. manifest의 `icons` 경로와 맞추세요.

---

### 4. Service Worker 등록 (`src/main.jsx`)
```js
import { registerSW } from 'virtual:pwa-register'

registerSW({ immediate: true })
```
(또는 플러그인 문서의 `injectRegister: 'auto'` 방식)

---

### 5. 빌드 & 확인
```bash
npm run build
npm run preview
```
브라우저에서 `http://localhost:4173/` 접속

DevTools → **Application**:
- **Manifest** 보이는지
- **Service workers** 등록됐는지 확인

---

### 6. 바탕화면에 설치 (로컬)
Chrome/Edge에서 `localhost:4173` 열고:
- 주소창 **설치** 아이콘, 또는
- 메뉴(⋮) → **앱 설치** / **Install SnippetNote**

설치 후 시작 메뉴·바탕화면에서 앱처럼 실행.

**주의:** 로컬 PWA는 **`npm run preview` 없으면** 처음엔 안 열릴 수 있음. 매번 서버 켜기 싫으면 **7번 배포**가 더 낫습니다.

---

### 7. (추천) 배포 후 설치 — 서버 없이 쓰기
1. GitHub에 `codeRead` push  
2. [Vercel](https://vercel.com) 또는 Netlify 연결  
   - Root: `codeRead`  
   - Build: `npm run build`  
   - Output: `dist`  
3. 배포 URL 접속 → **앱 설치**

HTTPS + 고정 URL → **preview 매번 실행 불필요**.
